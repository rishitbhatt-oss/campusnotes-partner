# CampusNotes

CampusNotes is a student-focused academic notes management project.

## Features
- **Note Management:** Organize notes by subject.
- **Study Templates:** Maintain reusable study templates.
- **Academic Resources:** Store programming and mathematics notes.
- **Resource Sharing:** Share useful study resources.

## New Feature: Study Planning
- Create weekly study schedules
- Track completed topics
- Identify subjects requiring revision
- Maintain consistent study habits

## Technologies
- Markdown
- Git
- GitHub

## Study Progress Tracking

- Track completed study topics.
- Monitor weekly learning goals.
- Identify topics that need revision.
- Review academic progress regularly.

## Note Organization Fix

- Keep notes grouped under the correct subject.
- Use consistent titles for all study notes.
- Avoid duplicate entries when organizing notes.

## How to Use CampusNotes

1. Select the subject for which you want to organize notes.
2. Create or add notes under the selected subject.
3. Use study planning to schedule weekly learning goals.
4. Track completed topics and review pending topics.
